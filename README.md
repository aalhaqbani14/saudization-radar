# Saudization Radar — إعداد ونشر

موقع عربي شخصي يراقب **صفحات عامة** من وزارة الموارد البشرية، ويرسل بريدًا عند اكتشاف تغيير يحتمل ارتباطه بالتوطين.

## النشر (GitHub Pages)
1. أنشئ مستودع GitHub جديدًا وارفع **محتويات** هذا المجلد إلى جذر المستودع.
2. افتح Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
3. سيظهر رابط من نمط `https://USERNAME.github.io/REPOSITORY/` بعد النشر.
4. افتح Actions → Saudization Radar monitor → Run workflow لتنفيذ أول فحص (تأسيس خط أساس، **دون إرسال تنبيه**).
5. شغّله مرة أخرى لاحقًا بعد تغيّر المصدر. الفحص المجدول مرة يوميًا (06:15 UTC تقريبًا، وقد يتأخر).

## إعداد البريد
في المستودع: Settings → Secrets and variables → Actions → New repository secret، أضف:
- `SMTP_HOST` اسم خادم SMTP لدى مزود بريدك.
- `SMTP_PORT` عادة `465` أو `587`.
- `SMTP_USER` اسم المستخدم لإرسال البريد.
- `SMTP_PASSWORD` كلمة مرور تطبيق/اعتماد SMTP، **لا تضع كلمة مرورك الأساسية في الملفات**.
- `ALERT_EMAIL` بريدك الشخصي المستلم.
- `SMTP_FROM` اختياري، عنوان المرسل المسموح به لدى المزود.

لا تدعم كل خدمات البريد كلمات مرور التطبيقات أو SMTP المجاني. تحقق من إعدادات مزودك. لا تشارك الأسرار في المحادثة.

## حدود مهمة
- GitHub Pages **عام** حتى لو كان رابط الصفحة غير معلن. لا تضع بيانات داخلية أو خاصة.
- GitHub Actions يعتمد على حدود الخدمة وجدولها؛ قد يتأخر أو يتوقف، خصوصًا للمستودعات غير النشطة.
- الرصد مبني على **تغيّر النص المستخرج** من صفحتين رسميتين، وليس واجهة API حكومية. لا يضمن رصد كل قرار، وقد ينتج تنبيهات خاطئة. الصفحات الديناميكية قد لا تظهر نصوصها للاستخراج.
- تغيير صفحة الأخبار العامة لا يعني بالضرورة وجود قرار جديد. يجب مراجعة الرابط الرسمي، وقد يلزم لاحقًا توسيع مصادر المراقبة أو استخراج روابط الأخبار التفصيلية.
- لا توجد حماية دخول؛ كل من يملك الرابط يمكنه الاطلاع، وقد يكون المستودع عامًا أيضًا.
- عند أول تشغيل يتم حفظ نسخة مرجعية دون إشعار، حتى لا تُرسل إنذارات عن المحتوى القديم.
- إن فشل الوصول للموقع، تُظهر Actions الخطأ ولا ترسل تنبيهًا كاذبًا.

## تشغيل محلي
من المجلد شغّل `python -m http.server 8000` وافتح `http://localhost:8000` لعرض الصفحة. لتشغيل الرصد يدويًا: `python monitor.py` (يتطلب اتصال إنترنت).
