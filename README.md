# Saudization Radar — رادار قرارات التوطين

منصة شخصية لمتابعة تغيرات محتملة في صفحات **وزارة الموارد البشرية والتنمية الاجتماعية**، وعرض القرارات وتحليل المهن ونسب التوطين. رصد التغييرات آلي واستدلالي، وليس ضماناً برصد كل قرار.

## روابط المشروع
- الموقع: https://aalhaqbani14.github.io/saudization-radar/
- غرفة التحليل: https://aalhaqbani14.github.io/saudization-radar/intelligence.html
- تشغيل المراقبة والبريد: https://github.com/aalhaqbani14/saudization-radar/actions/workflows/radar.yml

## تشغيل تنبيهات Gmail — ثلاثة أسرار فقط
**لا تضع كلمة مرور Gmail الرئيسية ولا كلمة مرور التطبيقات في ملفات المستودع أو في المحادثة.**

1. فعّل **التحقق بخطوتين** في حساب Gmail. ثم افتح https://myaccount.google.com/apppasswords وأنشئ **كلمة مرور تطبيق** مخصصة باسم `Saudization Radar` إن كان الحساب يسمح بذلك.
2. افتح مستودع GitHub → `Settings` → `Secrets and variables` → `Actions` → `New repository secret`.
3. أضف الأسرار التالية كلّاً على حدة:

| اسم السر | القيمة |
| --- | --- |
| `RADAR_SMTP_USER` | عنوان حساب Gmail المُرسِل (مثلاً بريدك الشخصي) |
| `RADAR_SMTP_PASSWORD` | كلمة مرور التطبيق التي أنشأتها في Google، **وليست** كلمة المرور الرئيسية |
| `RADAR_EMAIL_TO` | عنوان المستلِم؛ يمكن وضع أكثر من عنوان مفصول بفاصلة (,) أو فاصلة منقوطة (;) |

التوصيل الافتراضي: `smtp.gmail.com` على المنفذ `465` عبر TLS/SSL. إذا كانت أسرار الإعداد القديم `SMTP_USER` و`SMTP_PASSWORD` و`ALERT_EMAIL` موجودة، فإن سير العمل يدعمها أيضاً. يمكن استخدام `RADAR_EMAIL_FROM` إذا اختلف عنوان المرسِل، بشرط أن يجيزه مزود البريد.

> يمكن توجيه نسخة للبريد الشخصي وبريد الدوام بفصل العنوانين بفاصلة. لا يُنصح بإرسال معلومات موظفين أو بيانات منشأة سرية إلى هذا الموقع العام.

## اختبار إرسال رسالة الآن
1. افتح https://github.com/aalhaqbani14/saudization-radar/actions/workflows/radar.yml
2. انقر `Run workflow`، واختر فرع `main`.
3. فعّل خيار **Send a test email only** ثم انقر `Run workflow`.
4. ستظهر وظيفة `Send explicit test email`. عند نجاحها سيظهر `EMAIL_SENT: test` في سجل الوظيفة. تحقق من `Inbox` ثم `Spam` في Gmail.

**الاختبار يرسل رسالة فعلية** بعنوان `Saudization Radar | اختبار إشعارات البريد`، ولا يراقب موقع الوزارة أثناء تشغيل الاختبار، ولا يدّعي وجود قرار جديد.

إذا ظهرت رسالة `Email settings missing` فأحد أسرار GitHub غير مضبوط. وإذا ظهر خطأ `535` فتحقق من كلمة مرور التطبيق أو سماح حساب Google باستخدامها.

## شكل الإشعارات المحسّن
- رسالة عربية احترافية بألوان Saudization Radar مع دعم HTML ونسخة نصية احتياطية.
- يظهر اسم المرسل **Saudization Radar** وتحتوي الرسالة على مقتطف التغيير والمصدر ورابط رسمي مباشر.
- النسب والتواريخ تُستخرج من **النص المضاف** فقط إن ظهرت فيه؛ لا يصفها النظام بأنها «قديمة/جديدة» أو «سارية» تلقائياً، حتى لا يفترض صدور قرار.
- يمكن إعادة اختبار البريد من **Run workflow → Send a test email only**. رسالة الاختبار لا تزعم وجود قرار جديد.
- أضيف فحص برمجي مستقل بدون إرسال رسائل، للتأكد من صحة تنسيق البريد وأمان المحتوى المقتبس.
- تشغيل اختبارات القالب محلياً: `python -m unittest -v test_email_templates.py`.

## التنبيهات التلقائية
- الفحص مرتان يومياً الساعة **08:15 و17:15 بتوقيت الرياض** (05:15 و14:15 UTC)، مع احتمال التأخير حسب GitHub Actions.
- يراقب حالياً صفحتَي [الأخبار](https://www.hrsd.gov.sa/media-center/news) و[الأدلة الإجرائية](https://www.hrsd.gov.sa/knowledge-centre/decisions-and-regulations/regulation-and-procedures/evidence). هذه المراقبة لا تغطي كل مصادر القرارات بصورة كاملة.
- عند ظهور تغيير نصي يحتوي على ألفاظ مرتبطة بالتوطين، يتم تسجيله وتنبيه المستلمين إذا كانت الأسرار مفعلة.
- التشغيل الأول لمصدر جديد يحفظ خط أساس **دون إرسال تنبيه كاذب**. ولا يُرسل بريد إذا لم يُكتشف تغيير متعلق بالتوطين.
- لم يتم التحقق من إرسال البريد الفعلي إلا بعد نجاح `Send explicit test email`.

## أمان وقيود
المستودع وموقع GitHub Pages عامّان. تُخزن أسرار البريد في **GitHub Actions Secrets** ولا تُنشر في صفحات الموقع. لا تحفظ بيانات موظفين، معلومات داخلية، أو كلمات مرور في الملفات. قد تختلف صفحة الوزارة ديناميكياً أو تتغير دون قرار تنظيمي؛ لذلك كل إشعار هو **تغيير محتمل يجب التحقق منه من المصدر الرسمي**.

## تشغيل محلي
`python -m http.server 8000` لعرض الصفحة، و`python monitor.py` لفحص الصفحات مع اتصال إنترنت، و`python monitor.py --test-email` لاختبار SMTP عند ضبط متغيرات البيئة.
