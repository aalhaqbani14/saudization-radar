حدود البيانات: آخر لقطة معلنة للقوى العاملة هي 3 نوفمبر 2026. الأدوات تستخدم بيانات مجمعة ومصادر الرادار الحالية، ولا تتصل بحسابات قوى أو السجل التجاري. لا تعرض «100% امتثال»، ولا تغيّر الأعداد أو النسب أو القرارات تلقائيًا.

    5. غرفة مراجعة الاعتمادات

    جهّز سجل مراجعة محليًا وصدّره لمشاركة مؤمنة عبر قنوات الشركة؛ لا تُنشئ هذه الصفحة اعتمادًا رسميًا أو صلاحية دخول.

    مسودات محلية · لا مزامنة
    لا توجد مراجعات محفوظة. المسودات تحتفظ بها الصفحة مؤقتًا حتى إغلاقها أو تصديرها.
    القرارحالة المسودةالمراجعالملاحظات

    للاعتماد المشترك بصلاحيات موثقة وسجل تدقيق مركزي، يلزم تشغيل غرفة العمليات المشتركة على قاعدة بيانات خاصة مع تسجيل دخول وصلاحيات. إعداد الربط السحابي الحالي غير مفعّل؛ حزمة JSON ليست توقيعًا ولا اعتمادًا.
